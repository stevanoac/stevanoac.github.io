ai builder

so this was a project i built in 2025 that used spigot and python. i made a spigot plugin that allowed you to input your api key for anthropic, gemini, openai, or opencode. and you could prompt the ai to build you something. the ai would then use the python library "mcschematic" to build. then use world edit to paste the schematic in game.
