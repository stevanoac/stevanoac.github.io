discord bot

This was my own personal discord bot I made to link minecraft and discord. the bot would send join/quit messages to a discord channel, and send messages to and from the discord channel.

This project was made in 2025.

some features:

  • join message
  • quit message
  • discord messages from minecraft
  • minecraft messages from discord
