mango

This project was also made in 2025 and was made alongside Autumn.

some features:

  • ranks
  • profiles
  • punishments
  • staff mode
  • chat control
  • chat filter
  • staff alerts, chat and bungee integration
  • maintenance mode
  • mongodb integration
  • settings
  • integration with autumn
  • and so, so much more
