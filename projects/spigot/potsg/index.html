potsg

PotSG was a gamemode which originally was created by the Kohi server. This was my interpretation of it.

This project was created in 2025.

The whole point of PotSG is that you loot chests to gain loot and defeat your enemies. Though the items resemble what would commonly be used in HCF. As well as instead of a custom map, the map would be a default world with randomly generated structures.

some features:

  • potsg game loop
  • custom generating feast
  • custom shrinking border
  • game queuing
  • bungee hub switching
  • mongodb integration
  • multiple worlds
  • multiple games hostable at the same time
  • randomly generating structures via schematic files
  • and many more features
